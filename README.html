📂 1. 이 프로젝트에 포함된 파일들

목사님께 드리는 파일은 다음과 같이 구성되어 있습니다.

📁 인평교회주보/
├── home.html   # 시작 화면 (전체 페이지 안내)
├── index.html   # 성도님들이 실제로 보는 주보
├── edit.html   # 주보 내용 편집 화면
├── qr.html   # QR 코드 생성 페이지
├── archive.html  # 이전 주보 보관함
├── print.html   # A4 인쇄용 주보
├── README.html  # 이 사용 설명서
└── 📁 data/
    └── bulletin.json  # 주보 내용이 담긴 파일 (매주 갱신)
💡
가장 중요한 파일은 data/bulletin.json 하나입니다. 매주 이 파일 하나만 바꾸면 주보 내용이 바뀝니다. 나머지 파일은 처음 한 번만 올리면 끝!

🐙 2. 깃허브 계정 만들기 · 저장소 만들기

깃허브(GitHub)는 파일을 무료로 인터넷에 올려주는 곳입니다.

  1. 깃허브 계정 만들기 github.com/signup 에 접속해서 이메일·비밀번호·사용자명(예: inpyeong-church)을 입력해 무료 계정을 만드세요.
  2. 저장소(Repository) 만들기 로그인 후 오른쪽 위 + 아이콘 → New repository 클릭.
    • Repository name: inpyeong-bulletin (원하는 이름 아무거나 가능)
    • Public 선택 (성도님들이 볼 수 있어야 하니 반드시 Public)
    • Add a README file 체크
    • 맨 아래 Create repository 클릭
📝
Public / Private란? Public = 누구나 볼 수 있음 (주보에 필요), Private = 나만 볼 수 있음. 주보는 반드시 Public이어야 성도님들이 접속할 수 있습니다.

📤 3. 주보 파일 업로드하기

목사님이 받으신 모든 파일(HTML 파일들 + data 폴더)을 깃허브에 올립니다.

  1. 저장소 화면에서 "uploading an existing file" 클릭 방금 만든 저장소 화면에 "Add file → Upload files" 버튼이 있습니다.
  2. 파일 전체를 드래그해서 넣기 내려받으신 주보 폴더 안의 모든 파일과 data 폴더를 한 번에 끌어다 업로드 영역에 놓으세요.
  3. Commit changes 클릭 페이지 맨 아래 초록색 Commit changes 버튼을 누르면 업로드 완료!
⚠️
data 폴더째로 함께 올려주세요. bulletin.json이 폴더 안에 있어야 주보가 정상 작동합니다.

🌐 4. GitHub Pages로 인터넷에 공개하기

GitHub Pages는 깃허브의 무료 홈페이지 서비스입니다. 이걸 켜면 https://사용자명.github.io/저장소이름/ 주소가 만들어집니다.

  1. 저장소 위쪽 Settings 탭 클릭
  2. 왼쪽 메뉴에서 Pages 클릭
  3. Source 설정 Source를 Deploy from a branch로, Branch를 main / /(root)로 선택 후 Save.
  4. 1-2분 기다린 뒤 위쪽에 나타나는 주소 확인 Your site is live at https://사용자명.github.io/inpyeong-bulletin/
    여기서 홈 화면은 home.html, 주보 바로 열기는 뒤에 index.html을 붙이시면 됩니다.
💡
보통 주보 링크는 .../index.html로 안내하시면 성도님들이 바로 주보 화면을 볼 수 있어 편합니다.

📱 5. QR 코드 만들어 성도님께 안내하기

  1. 이 프로젝트의 qr.html 페이지 열기 홈 화면에서 QR 코드 타일 클릭.
  2. 주소 붙여넣기 4번 단계에서 만든 https://.../index.html 주소를 입력창에 붙여넣으세요.
  3. 이미지 다운로드 → 종이 주보/게시판에 인쇄 어르신 성도님도 스마트폰 카메라만 켜서 QR을 비추면 주보가 저절로 열립니다.
✝️
어르신 안내 문구 예시: "카메라 앱을 켜서 이 그림을 비추기만 하시면 주보가 열립니다. 앱 설치 필요 없습니다."

🔄 6. 매주 주보 내용 바꾸는 방법

여기가 가장 자주 하시게 될 작업입니다. 두 가지 방법 중 편하신 걸로 하세요.

방법 A. 편집 화면에서 바꾸기 (초보자 추천)

  1. edit.html 열기 홈 → 주보 편집 타일 클릭.
  2. 내용 수정 예배 날짜, 찬송, 성경 봉독, 설교 제목, 교회 소식 등 필요한 부분만 바꾸세요.
  3. 💾 브라우저 저장 → 미리보기 미리보기로 실제 어떻게 보이는지 확인하세요.
  4. 📥 JSON 다운로드 bulletin-20260913.json 같은 파일이 다운로드됩니다.
  5. 깃허브에 올리기 깃허브 저장소 → data 폴더로 들어가서 → Add file → Upload files → 방금 받은 JSON 파일을 드래그. 단, 이름을 bulletin.json으로 바꿔서 올려야 합니다 (기존 파일을 덮어씀).
    💡
    더 쉬운 방법: 깃허브에서 기존 data/bulletin.json을 클릭 → 연필 아이콘 🖉 Edit 클릭 → 전체 내용을 지우고 → 방금 다운로드한 파일의 내용을 붙여넣기 → Commit changes.
  6. 1-2분 뒤 새로고침 성도님들의 주보 페이지도 자동으로 새 내용으로 바뀝니다!

방법 B. JSON 파일 직접 편집 (익숙해지신 뒤)

깃허브에서 data/bulletin.json을 클릭 → 연필 아이콘 🖉 → 원하는 부분만 수정 → Commit changes.

⚠️
JSON 파일은 쉼표(,)와 따옴표(")를 정확히 지켜야 합니다. 실수하시면 주보가 안 뜰 수 있어요. 익숙해지시기 전엔 방법 A를 추천드립니다.

이전 주보 보관하기

새 주보를 올리기 전에, 보관함 페이지에서 [💾 현재 주보 보관함에 추가]를 누르시면 브라우저에 이전 주보가 저장됩니다. 완전한 영구 보관을 원하시면 JSON 다운로드 파일을 깃허브의 archive/ 폴더에 2026-09-13.json처럼 날짜별로 저장하세요.

💡 7. 실전 팁 & 자주 묻는 질문

Q. 찬송 악보 이미지는 어떻게 넣나요?

악보 이미지 파일을 깃허브 저장소에 images/hymn370.jpg처럼 올리신 뒤, 편집 화면 → 해당 찬송 항목 → 악보 이미지 URL에 images/hymn370.jpg를 입력하세요.

Q. 성경 본문 링크는 어떻게 연결되나요?

주보에서 성경 봉독을 누르면 대한성서공회 온라인 성경으로 이동하는 링크가 자동으로 표시됩니다. 본문은 편집 화면에서 개역개정으로 직접 입력하시면 됩니다.

Q. 어르신 성도님들이 글씨가 작다고 하시면?

주보 화면 오른쪽 위 가 · 가 · 가 버튼으로 글자 크기를 3단계로 조절할 수 있습니다. 또 옆의 ◐ 버튼으로 밤에 보기 편한 어두운 모드로 바뀝니다. 한 번 설정하면 다음에도 그대로 유지됩니다.

Q. 인터넷 없이도 볼 수 있나요?

최초 한 번 열어보시면 폰에 잠깐 저장되지만, 완전한 오프라인 사용을 원하시면 인쇄용 주보(print.html)를 PDF로 저장해 카톡으로 보내드리는 방법이 있습니다.

Q. 헌금 계좌 정보는 안전한가요?

계좌번호는 공개적으로 노출됩니다(누구나 볼 수 있는 페이지이므로). 이는 대부분 교회가 하는 방식이지만, 민감하시다면 실제 계좌 대신 담임목사에게 문의 같은 문구로 두시는 것도 방법입니다.

Q. 앞으로 유지보수는 어떻게 하나요?

  • 주보 내용만 바꾸실 거라면 → 매주 bulletin.json만 갱신
  • 디자인·기능 개선이 필요하면 → 다시 저를 찾아주세요 🙂
