# 인평교회 온라인 주보

경상북도 칠곡군 북삼읍 인강8길 34 · 채수호 목사 담임

## 📖 사용법

**초보자용 자세한 설명서는 `README.html` 파일을 브라우저로 열어 확인하세요.**

## 🚀 빠른 시작

1. 이 저장소를 **Public**으로 만들고
2. **Settings → Pages → Source: Deploy from a branch → main → /(root)** 설정
3. 잠시 후 `https://사용자명.github.io/저장소이름/index.html` 에서 주보를 볼 수 있습니다

## 📂 파일 구성

| 파일 | 용도 |
|---|---|
| `home.html` | 시작 화면 (전체 페이지 안내) |
| `index.html` | 실제 주보 화면 (성도님들이 보시는 페이지) |
| `edit.html` | 주보 내용 편집 화면 |
| `qr.html` | QR 코드 생성 페이지 |
| `archive.html` | 이전 주보 보관함 |
| `print.html` | A4 인쇄용 주보 |
| `README.html` | 사용 설명서 (초보자용) |
| `data/bulletin.json` | **주보 내용** (매주 갱신) |

## 🔄 매주 주보 업데이트

1. `edit.html` 열기 → 내용 수정 → **📥 JSON 다운로드**
2. 다운받은 파일을 `data/bulletin.json`으로 이름 변경 후 깃허브에 덮어쓰기
3. 1-2분 뒤 자동 반영

## ✝️ 특징

- 앱 설치 없이 카메라 QR로 열림
- 어르신 가독성 최우선 (글자 크기 3단계 조절)
- 다크 모드 지원
- 찬송/성경/설교를 탭하면 팝업으로 상세 표시
- 개역개정 본문 + 대한성서공회 링크
- 인쇄용 A4 판형
- 이전 주보 보관함
